# Tabla Hash en C

## Descripción

Implementación de una tabla hash en lenguaje C, basada en la estructura propuesta en clase.

## Características

- Claves de tipo cadena de caracteres.
- Valores enteros.
- Función hash basada en la multiplicación por 31.
- Tabla de 10 posiciones.
- Resolución de colisiones mediante listas enlazadas.
- Inserción y actualización de elementos.
- Búsqueda de claves.
- Eliminación de elementos.
- Visualización de la tabla.
- Liberación de memoria dinámica.

## Compilación

```bash
gcc -Wall -Wextra -std=c11 -O2 tabla_hash.c -o tabla_hash
```

## Ejecución

```bash
./tabla_hash
```

## Lenguaje

C (C11).
